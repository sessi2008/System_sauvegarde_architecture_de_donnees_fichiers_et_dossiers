# Security policy

The project is in early development. Please do not use it on critical production data or trust an inventory without previewing it.


## Reporting a vulnerability

Do not post exploitable path samples or sensitive drive inventories in public issues. Report security problems privately through GitHub's repository Security tab (Private vulnerability reporting, if enabled). If that option is not available yet, contact the maintainer through the email address listed on their GitHub profile. Include affected version, reproduction steps using sanitized paths, and impact.
