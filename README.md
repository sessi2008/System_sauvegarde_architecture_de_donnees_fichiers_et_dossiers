# System_sauvegarde_architecture_de_donnees_fichiers_et_dossiers
IL y a arrive des fois, où il est très probable qu'on puisse perdre nos donnees et qu'ils soient irrecuperables 
Cependant ce qui nous importe nous a ce instant ce n'est pas les donnees même en question, c'est l'arborescence exacte des fichiers, dossiers present sur le disque dur endommagé par exemple. 
Cette situation m'est deja arrivée et j'ai perdu plus d'un Tera de donnees mais ce qui m'importais c'etait la façon dont tout étaient organisés sur le Disque dur en question.
c'est pour cette raison j'ai penser a creer ce depot qui peut te permettre de recreer l'architecture exacte enregistrée avec un autre outil nommée wiztree, c'est de sa base de sauvegarde d'arborescence que je suis partir pour convevoir ce systeme en python qui permet de faire la route inverse pour pourvoir creer les fichier exactement comme elles etaient, mais une petite subtilité, j'ai bien dit que ce system vous serait utile si vous ne vous preocuppé pas de la recupration des donnees mais de l'arborescence d'organisation.
Le systeme vise a creer les dossiers exactes avec leurs noms exactes, et les fichiers dans les dossiers exactes sauf que les fichiers seront vides, cependant vous serez en mesure d'identifié le type de fichier, le dossier dans lequel elle se trouve et tout le reste
